# SpaceMouse
 Simple Python for SpaceMouse via HID.
See space_mouse_demo.py for example usage.
see space_mouse_controller.py for an example class that does high-level event handling.
See space_mouse_event_handler.py for the class that does low-level event handling.

See [SpaceMouse](https://www.3dconnexion.com/).
See [HID](https://en.wikipedia.org/wiki/USB_human_interface_device_class).
See [LelandGreen](https://lelandgreen.com/).
